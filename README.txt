CHRIS JOEL INDINO - PERSONAL PORTFOLIO
=====================================

PROJECT STRUCTURE
- index.html: Main portfolio webpage
- styles/style.css: Website styling
- assets/profile.jpg: Profile photo

HOW TO VIEW
1. Extract this ZIP file.
2. Open the indino-project-1 folder.
3. Double-click index.html to open it in your web browser.

HOW TO EDIT
- Edit the text and section content in index.html.
- Edit colors, spacing, and layout in styles/style.css.
- Replace assets/profile.jpg with another photo if desired, keeping the same filename.

GITHUB PAGES
Upload the contents of this folder to a GitHub repository named indino-project-1.
In the repository, open Settings > Pages.
Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
Wait for GitHub Pages to publish the site. Your URL will appear in the Pages settings.

NOTE
The site uses Google Fonts when an internet connection is available. The rest of the layout is local.
